# Plane-aware target-query validation

This private experiment tests a materially different image head on the authenticated cached RadImageNet tokens. The candidate explicitly encodes six clinical sequence slots and three within-slot slice positions, contextualizes tokens with a two-layer transformer, and uses twelve learned finding queries for target-specific cross-attention.

It is compared against the existing simple target-attention head on identical non-gold report-group splits across five seeds. All 58 organizer-labelled studies remain absent from fitting, validation, stopping, and selection, and are used only for final image-only evaluation. No competition submission can be created.
